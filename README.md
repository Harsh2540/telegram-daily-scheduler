# Telegram Daily Scheduler

## Setup (Windows)
1. Extract this ZIP.
2. Open the folder, click the File Explorer address bar, type `cmd`, press Enter.
3. Run `npm install` and then `npm start`.
4. Open http://localhost:3000 in Chrome.
5. Enter your Telegram Bot Token and Channel ID in Channel setup.
6. Add as many text, image, or GIF posts as you like, each with its own date and time.

Requires Node.js 18+. Add the bot as a channel administrator with permission to post. Keep the server running; for delivery while your PC is off, host it on an always-on Node.js server. Upload limit 20 MB. Data is stored in data.json and token/channel settings in settings.json. Keep settings.json private.
